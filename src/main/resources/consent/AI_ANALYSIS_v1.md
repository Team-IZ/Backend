# AI 분석 이용 동의

## 1. 무엇에 동의하는 것인가

이용자가 제출한 **코드와 산출물을 AI가 분석**하여 학습 문제와 리포트를 생성하는 데 동의하는
항목입니다. 이 동의가 없으면 제출물은 분석되지 않으며 리포트도 생성되지 않습니다.

## 2. AI가 처리하는 정보

| 구분 | 처리되는 내용 |
|---|---|
| 제출물 | 제출한 코드 저장소의 소스 코드, 업로드한 압축 파일의 내용 |
| 과제 정보 | 교안·문제·요구사항 등 과제 수행에 필요한 자료 |
| 응답 | 이용자가 작성한 문제 응답 |

**이름·이메일 등 신원 정보는 분석 요청에 포함하지 않습니다.** 분석은 제출물과 과제 맥락만을
대상으로 하며, 결과는 서비스가 다시 해당 이용자의 기록에 연결합니다.

## 3. 이용 목적

- 제출 코드의 이해도 점검 문제 생성
- 응답에 대한 평가와 피드백 생성
- 학습 리포트(도달 수준, 보완이 필요한 개념 등) 생성

**성적 산출이나 인사·채용 판단의 유일한 근거로 사용하지 않습니다.** AI가 생성한 결과는 학습 참고
자료이며, 오류가 포함될 수 있습니다.

## 4. 보유 및 이용 기간

분석 결과와 생성된 리포트는 소속 기관이 설정한 보존기간(**90일 · 180일 · 365일 중 택일**) 동안
보관한 뒤 파기합니다. 회원 탈퇴 시에는 그 시점에 파기합니다.

## 5. 처리 위탁 및 국외 이전

분석은 서비스가 운영하는 분석 서버와 그 서버가 호출하는 **생성형 AI 모델 제공자**를 통해
수행됩니다.

> **[확인 중]** 사용하는 AI 모델 제공자의 서버 소재지(국내·국외)와 국외 이전 여부는 현재 확인
> 중이며, 확인되는 대로 이 문서를 개정하여 **이전받는 자, 이전 국가, 이전 항목, 이전 일시와 방법,
> 이용 목적과 보유 기간**을 명시합니다. 개정 시 문서 버전이 올라갑니다.

## 6. 동의를 거부할 권리와 거부 시 불이익

이 동의는 **거부할 수 있습니다.** 다만 제출물 분석과 리포트 생성이 서비스의 핵심 기능이므로,
동의하지 않으면 **교육생 계정으로는 서비스를 정상적으로 이용할 수 없습니다.** 그 밖의 불이익은
없습니다.
