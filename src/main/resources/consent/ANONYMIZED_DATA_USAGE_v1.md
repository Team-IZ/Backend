# 익명 데이터 서비스 개선 활용 동의 (선택)

## 1. 무엇에 동의하는 것인가

**개인을 식별할 수 없도록 처리한 데이터**를 서비스 품질 개선에 활용하는 데 동의하는 항목입니다.
**이 항목은 선택이며, 동의하지 않아도 모든 기능을 그대로 이용할 수 있습니다.**

## 2. 활용되는 정보

이름·이메일·소속 기관·기수 등 **개인이나 기관을 특정할 수 있는 값을 모두 제거한 뒤**의 다음과 같은
집계·통계 정보만 활용합니다.

- 문제 유형별 정답률, 평균 소요 시간
- 자주 나타나는 오답·오류 패턴
- 기능별 이용 빈도

**원본 제출 코드나 개별 응답 전문은 이 목적으로 활용하지 않습니다.**

## 3. 이용 목적

- 문제 난이도와 출제 방식 개선
- 분석·평가 품질 개선
- 서비스 기능 개선 우선순위 판단

## 4. 보유 및 이용 기간

개인을 식별할 수 없도록 처리한 뒤에는 개인정보에 해당하지 않으므로, 통계 목적으로 기간의 제한 없이
보관할 수 있습니다. **다만 식별 가능한 원본은 「개인정보 수집·이용 동의」에 정한 기간이 지나면
파기합니다.**

## 5. 동의를 거부할 권리와 거부 시 불이익

이 동의는 **선택 사항**입니다. 동의하지 않아도 회원 가입과 서비스 이용에 **아무런 제한이 없으며,
어떠한 불이익도 없습니다.** 동의 후에도 언제든지 철회할 수 있습니다.
